# Numbers: Miller on writing about numbers

Load this file when the user wants the numbers in a draft checked: whether each stated value has its context and units, says what it means, names what it is compared with or judged against, carries a sensible number of digits, is plausible, and, where significance is claimed, whether the words match the test result. It applies to any part of a research article, thesis, dissertation or proposal that states numbers.

**Every rule below is Miller's.** Her books were not available to check in full, so rules cite their chapters as reported in the publisher's own study guides and in a published review, by chapter and item. Where she gives no rule, this file says so rather than supplying one. Nothing here is a general writing preference.

*Sources and how they are cited are listed at the end of this file.*

## How this file relates to the other files

*Procedure for this skill, not a rule of Miller.* This file covers numbers that are stated. Other files cover the rest:

- **Vague quantities** (*about 40*, *many*, round numbers used loosely, *how much*): `rules/vagueness.md`.
- **What the text around a table or figure says** (restating values, highlighting, exceptions): `rules/data-commentary.md`. Miller's own advice on describing patterns (generalization, example, exceptions) and on choosing between prose, a table and a chart is not repeated here, because that file and `rules/argument.md` (rule 6) already cover it.
- **How strongly a claim that rests on a number is stated**, and what backs a contested warrant: `rules/claims.md` and `rules/argument.md`. Miller's chapter on causality is not repeated here for the same reason.
- **Why a methodological choice was made** (a grid size, a threshold set by the author): `rules/methods.md` (rule 6) and `rules/methods-structure.md` (rule 4). Rule 5 here covers what a reported value is judged against.
- **Defining technical terms:** `rules/informativeness.md` and `rules/unpacking.md`.
- **Health research:** misleading metrics, causal wording and selective reporting of significant results are in `rules/spin.md`; minimum reporting is in `rules/reporting.md`.

## How to apply this file

*Procedure, not a rule of Miller.*

1. **Mark every stated number** in the passage: values, differences, ratios, percentages and test results.
2. **For each, check its context and units** (rules 1–2), then **what it means and what it is compared with or judged against** (rules 3–5).
3. **Check its digits and whether it is plausible**, and that the same value agrees wherever it appears (rules 6–7).
4. **Where the text speaks of significance**, apply rules 8–9.
5. **Propose revisions citing the rule.** Never supply a value, unit, reference value, standard or test result; where one is missing, ask the author for it.
6. **Run the checklist** at the end.

## Rules

### 1. Give each number its context

*Source: Miller 2015, ch. 2 (SG 2015, Suggested course extensions 2, A.1, B.1).*

Miller's study guide asks a reviewer whether the context of a study is specified and, if not, which of the Ws (such as who, what, when and where) are missing or poorly defined (A.1); a description of an association should give the Ws, the units, the direction and the magnitude (B.1).

- For each number, check that the reader can tell what was measured, for which cases, when and where. Flag a number whose case, period or place cannot be recovered from the sentence or its paragraph, and ask the author for it.

### 2. State the units, and make them consistent before comparing

*Source: Miller 2015, chs. 2 and 4 (SG 2015, Suggested course extensions 2, B.1; Problem set 4, problem 5; Suggested course extensions 4, A.1.c; Bergman).*

A description of numbers should give their units (Suggested course extensions 2, B.1), and Bergman quotes Miller's warning that even rocket scientists make basic, easily avoidable mistakes about units. Her exercises ask the writer to state the system of measurement, the unit of analysis and the scale (for example, dollars or thousands of dollars) (Suggested course extensions 4, A.1.c), and to compare four specimens whose masses are given in pounds, grams, kilograms and ounces, asking what steps are needed before the comparison can be made (Problem set 4, problem 5).

- Check that every value has its unit, including percentages (percent of what) and differences (in what unit).
- Flag values compared across different units or scales, and values of the same quantity given in different units in different places.

### 3. Report each number and say what it means

*Source: Miller 2015, ch. 2 (SG 2015, Suggested course extensions 2, A.4.b–c, A.5).*

The study guide asks whether the values are reported (in the text, a table or a chart) and whether they are interpreted in the text (A.4.b–c), and whether the direction and magnitude of an association are specified (A.5).

- For each number that matters to the argument, check that the text says what it shows: which way it goes and how large it is. Flag a number left for the reader to interpret.
- For what the text should say about a table or figure as a whole, see `rules/data-commentary.md`.

### 4. Name the comparison and its reference value

*Source: Miller 2015, ch. 5 (SG 2015, Suggested course extensions 5, A.1.a–d, B.1.a–c).*

Miller distinguishes types of quantitative comparison, among them rank, difference, ratio and percentage difference or change (A.1.a). For each comparison the writer should identify the reference value, and whether it comes from the data or from another source, such as a historical value or a reference population (A.1.b); choose a comparison value suited to the topic and units (B.1.a); justify the type of comparison by the variable's level of measurement (B.1.c); and describe the results, not the mathematical steps of the comparison (A.1.d).

- For each comparison, name its type and its reference value: *5% of what*, *higher than what*. Flag a percentage or ratio whose base the reader cannot identify.
- Flag text that walks through the arithmetic instead of stating the result.

### 5. Judge a value against a stated reference

*Source: Miller 2015, chs. 3 and 4 (SG 2015, Problem set 4, problem 7; Suggested course extensions 4, A.3, B.4; Suggested course extensions 3, B.1.d).*

Miller asks the writer to identify the standards or cutoffs needed to judge a value (Problem set 4, problem 7) and, where a standard cutoff or pattern is used in the literature, to find a reference that explains how it is applied and interpreted (Suggested course extensions 4, A.3, B.4). Whether an effect is big enough to matter is judged from background facts about the topic (Suggested course extensions 3, B.1.d; see rule 8).

- Where the text calls a value good, poor, large, small, acceptable or accurate (*within 5%*, *close agreement*, *excellent*), check that it says what the value is judged against (a standard, a cutoff, or a reference value from another source such as earlier work) and gives the source.
- Ask the author for the reference; do not supply one.

### 6. Report digits and decimal places to suit the measurement

*Source: Miller 2015, ch. 4 (SG 2015, Problem set 4, problem 3; Suggested course extensions 4, A.1.c; Bergman).*

One of Miller's exercises gives a stopwatch accurate to the nearest tenth of a second and a nine-trial average of 10.44444444 seconds, and asks for a sentence reporting that average (Problem set 4, problem 3); another asks for the appropriate number of digits and decimal places for a mean in the text and in a table (Suggested course extensions 4, A.1.c). The book gives guidelines on the number of digits and decimal places by type of statistic and table (Bergman).

- Flag values reported with more digits than the measurement or the method can support, and ask the author what precision the instrument, data or model supports.
- Flag the same quantity given with different numbers of digits in different places.
- The number of digits for each type of statistic is in Miller's table, which was not available; see "Where Miller gives no rule".

### 7. Check that each value is plausible and agrees with the data

*Source: Miller 2015, ch. 4 (SG 2015, Problem set 4, problems 8 and 15; Suggested course extensions 4, B.3.c–f).*

Miller asks the writer to judge whether values make sense for their concepts and units (Problem set 4, problem 15), and to consider the definitional limits on a variable and how the concept, the units and the study's context affect its plausible range (Suggested course extensions 4, B.3.c–f). Another exercise asks whether sentences correctly reflect the table they describe (Problem set 4, problem 8).

- Flag values outside their definitional limits (a percentage above 100 where it cannot be, a negative quantity that cannot be negative) or implausible for the concept, units and setting, and ask the author to confirm them.
- Check that each value in the text agrees with the table or figure it comes from. *This skill's application:* where a value disagrees, or repeats one from another row or column, ask the author to confirm it rather than correcting it (see `SKILL.md`, *How to apply any rules file*, step 4).

### 8. Keep statistical and substantive significance apart

*Source: Miller 2015, ch. 3 (SG 2015, Problem set 3, problems 1–2; Solutions 3, problem 1; Suggested course extensions 3, B.1.d–e); Miller 2013, ch. 3 (SG 2013, Problem set 3, problem 1).*

Miller's chapter separates statistical significance from substantive significance. Her exercises ask whether statements correctly convey statistical significance and, if not, to rewrite them so the words match the numbers (Problem set 3, problem 1). The solutions mark as incorrect a p-value of 0.95 read as near-certainty that a difference is not due to chance, a p-value read as the size of a change, and the claim that a larger sample would make the difference itself larger: test statistics and p-values indicate statistical significance and do not measure the size of an association, and sample size does not affect the size of a difference (Solutions 3, problem 1). Substantive significance asks whether an effect is big enough to matter, judged from background facts about the topic (Problem set 3, problem 2; Suggested course extensions 3, B.1.d–e).

- Check that every statement about statistical significance matches the reported test result, and that a p-value or test statistic is not read as the size of an effect.
- Where the text calls an effect important or negligible, check that it gives the facts that show why (rule 5); a significant result is not by that alone an important one.
- In health research, also apply `rules/spin.md`.

### 9. Give the test result behind a statement of significance

*Source: Miller 2013, ch. 11 (SG 2013, Problem set 11, problems 1, 7, 10).*

Miller's chapter on choosing how to present statistical test results works with the forms a result can take: test statistics, p-values, confidence intervals, standard errors, and symbols that denote significance levels (for example, * for p < 0.05) (Problem set 11, problems 1, 7, 10).

- Check that each statement that a difference or estimate is (or is not) significant is accompanied by, or points to, the result it rests on.
- Check that any symbols for significance levels are defined.
- Which form to report is the author's choice for the audience and the journal; Miller's chapter is about that choice. Do not prescribe one.

## Where Miller gives no rule

Miller's guidelines on digits and decimal places by type of statistic are in a table of the book (Bergman), which was not available; this file gives no digit counts. Because guidelines vary by discipline, Miller tells readers to consult an appropriate manual of style (as reported by Bergman): follow the target journal's style or style manual for digits, for numerals versus number words, and for number formats.

The sources used here do not cover the uncertainty of physical measurements (instrument and model error, uncertainty budgets). This file gives no rule for it. Fields that report measured quantities often follow the international *Guide to the Expression of Uncertainty in Measurement* (JCGM 100:2008); check what the target journal expects. Miller also sets no number of numbers per paragraph or section.

## Example

*An illustration of this file's procedure, not Miller's.* Draft sentence, in a Results section: "The model reproduced the observed peak within 5%, and the modelled peak at gauge D was 2.4013 m, an excellent result."

- **Context (rule 1):** which peak (which event, which quantity: water level or discharge)? "The observed peak" names no gauge or date.
- **Comparison (rule 4):** *within 5%* of what? Name the type of comparison (relative error of the modelled peak against the observed one) and its reference value.
- **Reference (rule 5):** *excellent* is judged against nothing stated. Ask the author what the agreement is judged against: the uncertainty of the observations, a criterion used in the field, or results of earlier models, with a source.
- **Digits (rule 6):** 2.4013 m implies a precision of 0.1 mm. Ask what precision the gauge and the model support.
- **Agreement (rule 7):** if Table 2 gives the same value as 2.40 m, the text and the table disagree in digits; if it gives another value, ask which is right.
- **Revision:** keep the author's values and ask for the missing context, reference and precision; do not supply a criterion.

## Validation checklist

- [ ] Every stated number was marked
- [ ] Each number's context (what, for which cases, when, where) can be recovered (rule 1)
- [ ] Each value has its unit, and compared values share units and scale (rule 2)
- [ ] Each number that matters is interpreted, with direction and size (rule 3)
- [ ] Each comparison names its type and reference value (rule 4)
- [ ] Each judgement of a value names what it is judged against, with a source (rule 5)
- [ ] Digits suit the measurement, and the same quantity has the same digits throughout (rule 6)
- [ ] Values are plausible and agree with their tables and figures; any that do not were put to the author (rule 7)
- [ ] Statements of significance match the numbers, and statistical and substantive significance are kept apart (rule 8)
- [ ] Each statement of significance gives or points to its test result, and significance symbols are defined (rule 9)
- [ ] No value, unit, reference, standard or test result was invented
